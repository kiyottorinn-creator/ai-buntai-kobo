# 文体工房

自分の過去記事から「文体カルテ」を作り、AIの下書きのうち自分の書き方から外れた文だけを色で出すページです。
1つのHTMLファイルとJavaScriptだけで動きます。入力した文章は保存も送信もしません（外部通信ゼロ）。

- 手順1: 自分の過去記事を3本以上貼る → 文体カルテ（一文の長さ・文末の形・漢字の割合・つなぎ方の見本帳）
- 手順2: AIの下書きを貼る → 自分が使わない文末は赤、長い文は黄、漢字が多い文は青
- 手順3: AIから返ってきた文を貼る → 数字・固有名詞が動いていないかを照合

AIが書いたかどうかを判定する道具ではありません。文体の良し悪しを採点する道具でもありません。

見本に入っている文章は、青空文庫の寺田寅彦の随筆3本（保護期間満了）と、
Gemini に書かせた架空のブログ下書き1本です。
